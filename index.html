02

Contexto & Módulos del Proyecto

TA-DIN busca profesionalizarse para captar clientes en los sectores petrolero, minero y telefónico. La digitalización permite iniciar el proceso de certificación bajo las normas ISO 9001 e ISO 14001. Toda esta información se encuentra en la documentación digital y en la landing page.

Módulo A · Página Web

Interfaz pública optimizada para posicionar la presencia digital de TA-DIN, canalizar consultas mediante Google Forms y captar clientes potenciales de forma ágil.

Módulo B · Reloj Biométrico

Registra e integra las fichadas en tiempo real mediante hardware biométrico (ZKTeco) conectado a una base de datos MySQL para seguimiento de presentismo.

Módulo C · Página de RRHH

Procesa los datos de asistencia para generar paneles visuales, auditar marcaciones y contabilizar las horas laborales de los empleados.

Integración NFC

Tarjetas de presentación interactivas para reuniones o eventos comerciales que redirigen al cliente a la sección de contacto mediante NFC/QR.

Plataforma de RRHH

Módulos Internos

Dashboard Principal

Resumen en tiempo real del estado de red (IP/Puerto del reloj), empleados activos, fichadas diarias y últimos 5 movimientos.

Gestión de Empleados

Altas y bajas de personal. El ID de Reloj cargado debe coincidir exactamente con el número de enrolamiento asignado en el equipo ZKTeco.

Registros Crudos

Caja negra con todas las entradas/salidas sin procesar. Permite cargas manuales para justificar ausencias u olvidos bajo clave de administrador.

Horas Trabajadas

Calcula horas netas a pagar filtrando llegadas tardes y turnos incompletos. Exportación de liquidación mensual a Excel profesional.

Matriz Mensual

Mapa de calor visual para auditar el mes del personal mediante iconografía por estados de asistencia.

Configuración

Panel para parametrizar la IP del biométrico, definir turnos corporativos (mañana/tarde) y tolerancia de llegada tarde.

Seguridad y Confirmación de Privilegios

1. Control de Sesión Nativo ($_SESSION)

Toda navegación por rutas .php exige sesión activa iniciada en login.php. Si el token no es válido, redirige al inicio de sesión.

2. Confirmación de Privilegios Destructivos

Para acciones sensibles (cargas manuales o bajas), se exige la contraseña de administrador vía HTTP POST previa confirmación en DB.

Documentación Técnica & Operación

Documentación Técnica & Arquitectura

Módulo A · Web
  • Frontend: HTML5, CSS3 responsivo.
  • Hosting: DonWeb mediante FTP FileZilla.
  • Propósito: Captación de leads B2B.
Módulo B · Biométrico
  • Hardware: ZKTeco + ZKBioTime.Net.
  • Protocolo: TCP/IP en red local.
  • Tablas: USUARIO, LOG_MARCACION.
  • Algoritmo: Match 1:N (<1s).
Módulo C · RRHH
  • Stack: PHP 8, Bootstrap 5.3, JS, MySQL.
  • Renderizado: SSR con controladores PHP.
  • Tablas: empleados, registros_asistencia, configuracion.
  • Reportes: Exportación nativa a .xls.
Integración NFC
  • Tecnología: Dispositivos NFC pasivos.
  • Función: Transmite URL a smartphones para derivar tráfico al sitio web o formulario.

Manual de Usuario & Operación

1. Operación del Reloj Biométrico
  • Identificación: Rostro, huella, tarjeta RFID o Clave. Modo 1:N o 1:1.
  • Uso Correcto: Distancia de 0.5m para rostro. Huella plana en cristal (registrar índice/medio).
  • Contingencias: Memoria no volátil (opera offline y sincroniza post-conexión o por USB FAT32).
2. Leyenda Matriz Mensual de Asistencia

Lectura visual rápida dentro del software de RRHH:

Verde: Correcto
Naranja: Llegada Tarde
Azul: Turno Incompleto
Rojo: Ausente
Gris: Fuera de Turno
